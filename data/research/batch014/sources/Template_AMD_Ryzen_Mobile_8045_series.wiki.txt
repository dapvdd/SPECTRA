Common features of Ryzen 8045 notebook CPUs:
* Socket: FL1.
* All the CPUs support [[DDR5 SDRAM|DDR5]]-5200 in [[Multi-channel memory architecture#Dual-channel architecture|dual-channel]] mode.
* L1 [[Cache (computing)|cache]]: 64&nbsp;KB (32&nbsp;KB data + 32&nbsp;KB instruction) per core.
* L2 cache: 1&nbsp;MB per core.
* All the CPUs support 28 [[PCI Express#PCI Express 5.0|PCIe 5.0]] lanes.
* Native USB 40Gbps (USB4) Ports: 0
* Native USB 10Gbps (USB 3.2 Gen 2 operation mode) Ports: 4
* Includes integrated [[RDNA 2]] GPU on the [[Input/output|I/O]] die <span data-darkreader-inline-bgcolor="">with 2 CUs and clock speeds of 400</span>&nbsp;<span data-darkreader-inline-bgcolor="">MHz (base), 2.2</span>&nbsp;<span data-darkreader-inline-bgcolor="">GHz (boost)</span>{{efn-lr|Self identifies as "AMD Radeon 610M". See {{section link|RDNA 2#Integrated graphics processors (iGPs)}}.}}.
* Fabrication process: [[TSMC]] [[5 nm process|N5]] FinFET ([[7 nm process|N6]] FinFET for the I/O and graphics die).
